# Planner pentru activități și rutine de wellness

## Descriere

Aplicația Planner Wellness este destinată organizării activităților zilnice și a rutinelor de wellness într-un singur loc.

Utilizatorul poate adăuga, vizualiza, finaliza și șterge activități personale, precum rutina de skincare, administrarea vitaminelor, activitatea fizică și alte obiceiuri de îngrijire personală.

Fiecare activitate are un nume, o categorie, o prioritate și un status. Activitățile pot fi accesate și individual, printr-o pagină de detalii.

Interfața Botanical Wellness include o temă deschisă și una întunecată, design responsive și navigare între pagini.

Funcționalitățile propuse pentru dezvoltarea ulterioară includ remindere, monitorizarea stării de spirit, urmărirea ciclului menstrual și un mood board personal. Acestea nu sunt implementate în versiunea actuală.

## Data model

| Field | Type | Notes |
|---|---|---|
| id | number | Generated by JSON Server |
| name | text | Required, maximum 100 characters |
| completed | boolean | Default false |
| priority | fixed values | Low, Medium, High |
| category | fixed values | Self-care, Health, Fitness |
| user | relation | Planned for a later stage |

Sample activities:

1. Evening skincare — Self-care — Medium
2. Take daily vitamins — Health — High
3. 30-minute workout — Fitness — Low

The mock API contains five initial activities in `frontend/db.json`.

## How to run

The application uses React and Vite for the frontend and JSON Server for the mock REST API.

Open a terminal in the project directory:

```bash
cd frontend
npm install
```

Start the mock API:

```bash
npm run api
```

The API is available at:

`http://localhost:3001/activities`

Open a second terminal in the `frontend` directory and start React:

```bash
npm run dev
```

Open the local address displayed in the terminal, usually:

`http://localhost:5173/`

On Windows PowerShell, `npm.cmd` can be used instead of `npm`.

To verify the production build:

```bash
npm run build
```

The original HTML/CSS version from Stage 1 is preserved in the `mockup/` folder.

## Application routes

| Route | Description |
|---|---|
| `/` | Activity list and creation form |
| `/activities/:id` | Individual activity details |
| `/despre` | About Planner Wellness |
| `*` | 404 page for unknown routes |

Navigation is implemented using React Router without requiring a full page reload.

## API operations

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/activities` | Fetch all activities |
| GET | `/activities/:id` | Fetch one activity |
| POST | `/activities` | Create an activity |
| PATCH | `/activities/:id` | Update an activity |
| DELETE | `/activities/:id` | Delete an activity |

API requests are centralized in `frontend/src/api.js`.
